Week 6 · Set A · Design specification

ASCII Dropdown

Tone: ASCII Art — terminal-native menu with box-drawing borders, monospace glyphs, and cursor-prefix hover.

Anatomy

One row grid: icon column (28 px) · label (fluid) · trailing area (auto). Box-drawing characters frame the menu. ">" cursor prefix appears on hover.

┌─── Menu Title ──────────────────────────────┐
│                                              │
│  [ico]  Label Text             Shortcut  ⌘K  │  ← default
│                                              │
│> [ico]  Label Text             Shortcut  ⌘O  │  ← hover (> prefix)
│         ▲                      ▲              │
│         │                      │              │
│    icon col (28px)       right area           │
│                                              │
│  ── SECTION LABEL ─────────────              │
│  ·····································(div)   │
│                                              │
│  [ico]  Label Text             [badge]  12   │  ← badge
│  [ico]  Label Text                ──▶        │  ← submenu
│  [×]    Danger Item                ⌘⌫        │  ← danger
│                                              │
└──────────────────────────────────────────────┘

[+] New File ⌘N
