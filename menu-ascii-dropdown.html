Week 6 · Set A · Design specification

ASCII Dropdown

Tone: Monochrome cobalt blue on cream — DM Serif Display headers, Space Mono body, box-drawing character frame, ▸ cursor selector.

Anatomy

Box-drawing character frame (┌─┐│└─┘). Section labels woven into horizontal rules. Four-column item grid: cursor (18 px) · icon (18 px) · label (fluid) · trailing area (auto). ▸ triangle cursor slides in on hover. Version footer in bottom frame line.
