Week 6 · Style 2 · Design specification

Home Grid Dropdown

Tone: iOS Home app grid — SF Pro, soft gray tiles, green status dots, amber brightness slider, spring press animations with ripple from the pet app system.

Anatomy

Trigger button with home icon opens a dropdown panel. Panel contains a 2×3 grid of room tiles, a stats row (temperature, humidity, noise), and a brightness slider. Each tile has a status dot and label.
