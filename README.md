# UI Index

A collection of 12 interactive UI micro-studies, each a single self-contained HTML page.
Live site: **https://yuhanwu-klein.github.io/ui-index/**

## The 12 pieces

**Basic components**
- 01 Appearance Toggle — day/night + language switch with eclipse animation
- 02 Checkbox — daily journal list, sticky ink + sinking "done" items
- 03 Radio — abstract geometric age selector with hover reveal

**iPhone app pages**
- 04 Pets — Pinterest-style discovery feed with a sliding detail sheet
- 05 Puppy Prep — melting checklist with celebration confetti
- 06 Find your match — radio quiz that expands into dog matches with shuffle

**Mosaic glitch series**
- 07 Mood switch — drag-to-engage toggle with pink/green pixel checker
- 08 Pixel checklist — tasks that RGB-split and pixel-dissolve on completion
- 09 Pixel select — BIOS-style difficulty picker with scanline sweep

**Sci-fi engage series**
- 10 Engage — flat iOS form, deep-space gradient inside when active
- 11 Engage check — square checkboxes with the same cosmic fill
- 12 Engage select — radio circles sharing the engage visual language

## Running locally

Any static server works. For example:

```bash
python3 -m http.server 8787
```

Then open http://127.0.0.1:8787/
